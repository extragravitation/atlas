# Atlas of Extra Gravitation: identity

The logo (version G1, chosen 2026-11-22) and every file made from it. All files are generated by `make_brand.py`; edit the script, never the outputs.

```
python3 brand/make_brand.py            # SVG masters, PNGs, and the site's icons
python3 brand/make_brand.py --svg-only # SVG masters only
```

The PNGs need `rsvg-convert` and ImageMagick `convert`, and the Inter Tight and Source Code Pro fonts installed locally (the lockups, banner and share card contain text).

## The mark

A line, and five circles that leave it in a shallow arc, growing as they go. The line stands for Newtonian gravity on detected matter, the diagonal of the Atlas's main chart. The mark is drawn, not plotted from data. Colour shows position along the sweep and never stands for a dataset, so the mark makes no claim about which systems lie off the line.

## Rules

- **Clear space:** at least the largest circle's diameter on every side.
- **Minimum size:** 16 px, with the small-size artwork.
- **Type:** Inter Tight, Bold for the name, Regular for the subtitle.
- **Don't:** recolour single circles, add or remove circles, rotate the mark, or place it on busy images.
- Please use the logo only to refer to the Atlas.
