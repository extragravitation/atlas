## Points the rules did not settle

A. **R20 Table 7 MRT column labels do not match the data (important).** The IOP MRT byte description labels bytes 26-30, 37-41, 48-52 and 59-63 as logMChab, logMSalp, logMChabNIR and logMSalpNIR. The arXiv v1 Table 7 header orders the columns as Chab, Chab (NIR), Salp, Salp (NIR). The pattern of blanks in the MRT (bytes 37-46 and 59-68 are empty exactly for the systems with no NIR data in Table 2) matches the arXiv order. If the MRT labels were right, 30 systems would have a Salpeter mass but no Chabrier-NIR mass, while having a Chabrier-NIR mass that is 0.25 dex higher than Chabrier. I transcribed the values by byte position. I assigned IMF and bands from the arXiv header, and I kept the MRT label in `location` so it can be checked. The values themselves are the same in both versions. Only the labels differ. **Converters must not trust the MRT labels for this table.**

B. **R20 Table 6 MRT label.** The Einstein-radius column is labelled `Reff`, but its explanation reads "Einstein radius". The arXiv table header has R_Ein. I read it as θ_E (SIE). The errors are the printed "68% confidence interval", given as ±.

C. **R10 has no errors.** Table 2 prints b_SIE, log M_Ein and log M*Chab without uncertainties, and Table 1 prints R_eff without one. R10 shows the stellar mass for one IMF only (Chabrier). Salpeter values appear only in figures in R9 (Shu et al. 2015, Fig. 9), with no per-lens table.

D. **R10 stellar-mass aperture.** Table 2 states none. The R10 abstract says "In Shu et al., we have derived the total stellar mass of the S4TM lenses". I recorded "total" with that quote. The light profile is R10's own Table 1 fit (de Vaucouleurs, HST F814W, R_eff "in the intermediate axis convention"), so the record named for photometry is R10 itself: Shu et al. 2017, ApJ 851, 48. R9 (Shu et al. 2015) derives R_half from a core-Sérsic fit but prints no per-lens table of it. de Vaucouleurs implies n = 4, but no `sersic_n` row was written because the source does not print a number.

E. **R20 stellar-mass aperture** is not stated as a radius. The Table 7 note says "Stellar masses from the fit of stellar population synthesis models to photometric data". The photometry is the de Vaucouleurs-model magnitudes of Table 4, so I recorded "not stated". The inventory codes it as total. R20 prints two effective radii for some systems, CFHT (Table 4, 30 % typical uncertainty) and HST (Table 5). I recorded both, plus R21's R_eff in kpc as an alternative. Which one feeds §3.1 is for the rules to decide.

F. **R20 prints no M_E.** R21 Table 3 prints R_Ein in kpc (for example 6.65 kpc for SL2SJ022511-045433 and 4.84 kpc for SL2SJ084959-025142). I noted these but did not add them as rows, because `R_E` is not a listed quantity.

G. **Flatness.** None of R10, R20, R21 or R22 uses the word "flat". Each prints Ω_Λ with Ω_m (0.274 + 0.726 in R10; 0.3 + 0.7 in the SL2S papers). I recorded "not stated in words" and did not infer flatness.
