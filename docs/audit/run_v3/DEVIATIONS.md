# Audit v3: deviations and incidents during the run

1. **B packet for aeg-d-gc-baumgardt built defective (operational error, Claude).** The first packet-building loop was still running in the background after it had appeared to time out. After the GC packets had been rebuilt with the pilot's hash-verified copies of S5 and S7 (`--files`), that loop overwrote `/tmp/pk/B/aeg-d-gc-baumgardt` with a packet lacking both files, while its log still said 4 of 4 files were ready. Reader B was given that packet, and it correctly reported all 10 rows as unreadable for lack of the files. Found 2026-11-26 ~15:45Z, before any reading was compared with the Atlas. The loop was stopped, the packet was rebuilt (BRIEF, METHOD, rows and sources byte-identical to packet A; all 4 files hash-verified), and a fresh reader B was given it. The defective reading is kept unedited in `readings_void/b/aeg-d-gc-baumgardt/` and is not used. Every other packet was checked against its `sources.json`, and none was missing a file.
2. **S5 and S7 supplied from earlier copies.** vizier.idia.ac.za returned 504 Gateway Timeout on 2026-11-26. S5 and S7 were supplied with `--files` from the copies downloaded from the same host on 2026-11-25 for the dry run. Each was checked against its recorded content hash (`content_from`) by `aeg.fetch` before it went into a packet. This is plan §2.5's route; no mirror or other version was used.
