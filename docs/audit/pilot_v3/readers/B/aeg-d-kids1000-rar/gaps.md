# Method gaps — aeg-d-kids1000-rar/v3, rows m000003 and m000012

No step was blocked ("method incomplete": none). These are steps I had to infer, even where I'm confident of the result.

1. **Mapping from measurement_id to file and row.** METHOD.md does not say how `mNNNNNN` maps to a sample, file and data row. I took the mapping from rows.json (m000003 → KiDS-bright file, data row 3; m000012 → KiDS-bright file, data row 12). METHOD.md alone would not let a reader go from an id to an input.
2. **What counts as a comment line.** METHOD.md says "non-comment lines, counted from 1" but does not say what marks a comment. I took lines starting with `#` (the file has one such header line), so data row k is file line k+1.
3. **Column 1 label.** The file header calls column 1 `Radius(m/s^2)`, and the README defines it as "The mean projected distance from the lens center ... or in meter-per-second-squared for the RAR data". METHOD.md calls it g_bar and does not mention the header label. I followed METHOD.md (g_bar). Also, the README's "mean" wording and the rows.json "arithmetic midpoint of bin" wording do not obviously agree. Numerically, column 1 equals the arithmetic midpoint of the §2.1 bin edges for both rows (4.3030e-15 and 7.1310e-13), so the midpoint reading holds.
4. **Treatment of h70.** METHOD.md says ΔΣ is in h70 M☉ pc⁻² with h = 0.7 and is "used as released". I read that as no h-scaling: h70 = 1 at H0 = 70, which is the paper's convention at l. 165. METHOD.md does not say this explicitly.
5. **Constant evaluation.** METHOD.md gives the numbers and also says they come "through astropy ≥ 6.1". I used only the stated numbers (G = 6.67430e-11, M☉ = 1.98840987e30 kg, pc = 3.0856775814913673e16 m) and computed 4G·(1 M☉ pc⁻²) = 5.575329e-13 m s⁻² myself. I did not check astropy. The README's own constants (G = 4.52e-30 pc³ M☉⁻¹ s⁻², pc = 3.086e16 m) would give a slightly different value. The method rules them out, but it does not say so.
6. **Precision and rounding of outputs.** None is specified. I report g_obs to 7 significant figures and g_bar exactly as printed (5 significant figures).
7. **Location of S2.** sources.json gives S2's file as `arxiv/2106.11677v1.tar.gz`, but the packet has it at `files/2106.11677v1.tar.gz`. Its SHA-256 matches. The S1 tar and all seven listed member hashes also match.
8. **"§2.1" in the tex source.** The LaTeX has no printed section numbers. I took §2.1 to be `\subsection{Mass measurements with weak gravitational lensing}` under `\section{Theory}`, assuming Theory is section 2. The bin definition is at line 174, as stated.
9. **"Eq. 7 of the paper."** I identified it as `eq:gobs_from_ESD` (g_obs = 4GΔΣ) by counting labelled equations; it is the 7th. I did not check for unlabelled display equations.
10. **Isolation limit.** METHOD.md notes the limit is written as both 0.3 and 3 h70⁻¹ Mpc. l. 508 itself says "R < 3 \hMpc", while l. 595 gives the KiDS isolation limit as g_bar < 1e-13 m s⁻² and l. 619/709/748 use 0.3. The plotting rule (rows 1–8 not plotted) is fixed by row number, so it did not affect these values. The source's inconsistency remains. Note that a literal g_bar < 1e-13 m s⁻² cut would mark rows 1–9 as beyond the limit, because row 9 has g_bar = 7.358e-14. That leaves 6 points, not the 7 that METHOD.md and l. 508 cite.
