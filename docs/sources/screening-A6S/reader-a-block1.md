## Questions for the maintainer

1. **CC-BY copy of SLACS values (R11).** Zenodo 10.5281/zenodo.13366012 (CC-BY-4.0) includes `SLACS_table.cat`, a re-tabulation of Auger et al. 2009 (R7) values. Should the Atlas cite R7 or VizieR as the source of record and use the Zenodo file only as a licence route? Or should it use VizieR only?
2. **Spectroscopic SPS mass-to-light ratios (R25, R26, R28, R29).** These low-z lenses give a photometric luminosity inside the Einstein radius times a fixed-IMF (Kroupa) M/L from absorption-line or full-spectrum population fits. They do not give a photometric SED mass. Does this meet "luminosity plus a stated stellar-population mass-to-light ratio"? I marked them P.
3. **Image-separation Einstein radii (R25 SNL-1/2, R29) and single-image limits (R9 grade-C, R27).** Is half the image separation, with symmetric-lens corrections, an acceptable "lens model fitted to the lensed images"? Single-image systems give only limits; should they be excluded or held as a separate limits class?
4. **Kinematics-informed source redshifts (R19 zs,pdf; R21 photogeometric zs).** These use the velocity dispersion. I propose excluding those systems from the observed side as circular.
5. **Multiple observed-side versions for the same lenses.** SLACS has R5 SIE, R7 SIE and R12 power-law plus shear. SL2S has R20 SIE and R24 power-law. Dinos I is a lead. The choice of canonical model (or showing all as an assumption) should be fixed and hash-frozen before any comparison.
6. **R9 journal version.** Per-lens tables could not be confirmed (arXiv version only). R10's VizieR logM column carries R9's stellar masses for the S4TM lenses.
7. **SL2S sample assembly.** The SL2S sample needs R20 (models, SPS), R21 (redshifts) and R22 (5 new systems, updated SL2SJ021801). Should these be one combined package with per-row provenance?
