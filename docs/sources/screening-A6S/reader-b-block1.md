## Questions for the maintainer

1. **R7 metallicity prior.** The SLACS IX SED fits use a Gaussian metallicity prior drawn from the σ–metallicity relation (Gallazzi et al. 2005) at each lens's own velocity dispersion. Does this make the baryonic side "from a scaling relation / the system's own kinematics" under the not-circular rule, or is it an acceptable minor prior? R19 and R20 use the same code but state uniform priors (R19 explicitly; R20 unverified).
2. **Choice of SLACS stellar masses.** For the same lenses there are R7 (multi-band HST, BC03, Chabrier/Salpeter), R13 (SDSS ugriz, BC03 and Maraston, three IMFs, with an aperture-within-REin variant) and R9/R10 (single-band F814W SSP with fixed age and metallicity). Should these be one baryonic source plus an assumption range, or should a single source be chosen? Is single-band SSP scaling with fixed age and metallicity acceptable as a "stated stellar-population M/L"?
