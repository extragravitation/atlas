# Changelog

All notable changes to the Atlas are recorded here. Site releases (v0.1, …) are numbered separately from dataset versions (see `docs/decisions.md`, D-006 and D-010).

## Unreleased

- D-048: dwarf galaxies. LVDB is an index and the original papers are the record, read at source; circularised half-light radius; kinds whose label rests on dynamics go to A7 with an A7 map view (amends D-028 item 5). Frozen with it: the kind-basis rule (`docs/methods/D048_KIND_BASIS.md`), the M/L-by-metallicity interpolation (`aeg.ml_interp`), and `aeg-d-dwarfs/v1` REPRODUCTION.md with the LVDB index pinned to v1.1.1 (deviation #20).
- Globular clusters: D-039 stellar mass-to-light slider (`gc_stellar_ml`), from 0.53 × the population value (Kruijssen & Mieske 2009 dissolution bound) to each cluster's BC03 + Salpeter value (McLaughlin & van der Marel 2005 (M/L)2), asymmetric; effects computed from the registry formulas and checked by `formula_check`. `aeg-d-gc-baumgardt/v1` (pre-release, not yet deposited) gains the column `x_gc_baumgardt_ml_v_salpeter` and its source observables; transcription test now 3 182 values.
- New dataset `aeg-d-gc-baumgardt/v1` (data standard 2.0.0): 155 Milky Way globular clusters recorded, 64 plotted as one value each at the 3D half-light radius; tests 1 and 3 pass, test 2 FAIL on record (D-046), test 4 decided (D-047); independent second reading: 3 535 of 3 535 numbers agree. Site: plotted-only rows on the map, a distinct mark and colour for one-value-per-system data, and a system page for dispersion systems (status and reasons, profile figure, inputs, reproduction check).
- `aeg-d-gc-baumgardt/v1`: test 4 decided (Harris r_c is the half-power radius; Harris-only clusters recorded, pending a ruling); conversion core run (64 of 155 clusters plottable, reasons recorded); D-037 check published (3 pass, 1 fail, 148 not testable: released velocities cover fewer stars than the profiles).
